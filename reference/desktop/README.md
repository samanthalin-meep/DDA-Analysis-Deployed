# Desktop reference source

`ddalab_qt`, `ddalab_gui`, and `pyproject.toml` are unchanged copies of the supplied DDALAB Pooled 1.2.10 source from:

`102226/DDA_CrossTrials_I1_R3/03_execution_record/gui_app_build/DDALAB_Pooled_source/packages/ddalab/`

This source is retained as a reference for the browser interface, analysis defaults, data formats, and session compatibility. It is not included in the GitHub Pages deployment. The original macOS application remains at the repository root. The Rust engine is preserved separately in `vendor/dda-rs` with its MIT license.

Existing source-file notices remain authoritative. No new license is assigned to the supplied Qt source. The supplied `.ttf` files contain saved HTML, as in the original application; the interface uses a Helvetica Neue fallback. `IBM-Plex-LICENSE.txt` is retained for reference.
